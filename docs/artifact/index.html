Multi-agent orchestration platform

Orchestrix

One request becomes a planned, executed and reviewed deliverable. A supervisor plans a graph of subtasks, specialist agents run them in parallel with tools, a reviewer scores every result, and the run stops for a person before any risky step. Every step is checkpointed, traced and replayable.

Guarantees

What the platform enforces in code

Durable runs

Every graph step is checkpointed in Postgres. A worker that dies mid-run loses its lease, and another worker resumes from the last checkpoint without repeating tool calls.

People at the risky steps

OPA checks every tool call. Sensitive tools, low plan confidence, low review scores and budget caps raise a human gate; a second person decides, never the requester.

Untrusted content stays data

Fetched pages and uploads are wrapped, scanned for prompt injection and taint the subtask, so injected text can never trigger an action without approval.

Isolated code execution

The sandbox has no network, a read-only root filesystem, CPU, memory and time limits, and no storage credentials.

Every call accounted

Each model and tool call is recorded with tokens, cost, latency, the model that served it and why it was called.

Model-agnostic

Agents ask for a role. One setting maps roles to models; the defaults run on gpt-oss-120b over the VPN.

Run it locally

From a fresh clone to a running showcase

Everything runs in WSL Ubuntu with Docker Desktop. The full guide, with model switching and troubleshooting, is docs/RUN_LOCALLY.md in the repository.

  1. Install dependencies and create .env

    uv sync --all-packages --frozen
pnpm install --frozen-lockfile
make env      # then set REMOTE_LLM_API_KEY in .env

  2. Turn on the VPN and check every model

    make gateway-check

  3. Start the stack and seed demo data

    make dev
make seed

  4. Open the web app

    pnpm --filter @orchestrix/web dev     # http://localhost:5173
make dev-token                        # paste the token to sign in

  5. Run the showcase request

    uv run python scripts/showcase.py
Models

Change the model in one place

Add the model to infra/litellm/config.yaml, point a role at it in .env, and restart. No code names a model.

ORCHESTRIX_DEFAULT_MODELS={"planner":"gpt-oss-120b","specialist":"gpt-oss-120b","reviewer":"gpt-oss-120b","fast":"gpt-oss-120b"}
ORCHESTRIX_LOCAL_FALLBACK=false   # VPN models only
